# Documentation

This folder contains all research documentation, guides, and reference materials for the Bio-Aware Blended Spaces (BABS) project.

## Folder Structure

### **`/phases/`**
Detailed documentation for each project phase (Phase 1, 2, 3, 4).
- **Use this for**: Understanding phase goals, deliverables, status, and team assignments
- **Files**: `phase1.md`, `phase2.md`, `phase3.md`, `phase4.md`

### **`/guides/`**
Practical how-to documentation and workflow guides for contributors.
- **Use this for**: Getting started, setting up your environment, contribution workflows
- **Common files**: `getting-started.md`, `sensor-setup.md`, `middleware-configuration.md`

### **`/reference/`**
Reference materials and technical specifications.
- **Use this for**: Looking up terminology, understanding biosensor evaluation, reviewing precedent work
- **Contains**: 
  - `Evaluation of Biosensors.md` — Technical evaluation of available sensors
  - `Technological Terms Related to Biosensors.md` — Glossary and terminology
  - `Stage 1-README.md` — Foundational documentation from initial setup
  - `Precendent Uses of Sensors` — Historical context and prior implementations

### **`/research-notes/`**
Weekly research logs and ongoing documentation of project progress.
- **Use this for**: Tracking weekly progress, documenting decisions, logging challenges
- **Format**: `week-NN.md` files organized by week
- **SRDMPA Alignment**: Documents progress through Speculate, Research, Design, Make, Publish, Assess phases

### **`/setup/`**
Onboarding and environment configuration documentation.
- **Use this for**: Initial project setup, development environment configuration, tooling
- **Contains**: Researcher setup guides, project board instructions, setup scripts

## Key Documents

### **`Arc 1.md`**
Narrative report from the first major research effort/arc. Documents the foundational work, findings, and evolution of the BABS concept.

### **`index.md`**
Main entry point for documentation. Overview and navigation hub for all docs.

### **`repository-structure.md`**
Comprehensive guide explaining the rationale and organization of the entire BABS repository structure. Includes best practices for data management, code organization, and research workflows aligned with CHI methodology.

## How to Use This Folder

1. **New to the project?** Start with [guides/getting-started.md](guides/) or [index.md](index.md)
2. **Need technical details?** Check [reference/](reference/) for biosensor specs and terminology
3. **Want phase-specific info?** See [phases/](phases/) for your current phase
4. **Following the research progress?** Review [research-notes/](research-notes/) for weekly updates
5. **Setting up development?** Look in [setup/](setup/) for environment configuration

## Contributing to Documentation

- **Research Notes**: Add weekly progress updates to `research-notes/`
- **New Guides**: Add how-to documentation to `guides/` as you develop workflows
- **Phase Updates**: Keep phase files current as deliverables are completed
- **References**: Add new reference materials to `reference/` as needed

All documentation should follow the repository structure guidelines and maintain consistency with the SRDMPA research methodology.
